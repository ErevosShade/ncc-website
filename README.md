# NCC BIT Mesra — Website concept

A responsive, static website concept for **3 Jharkhand Composite Technical Company, NCC, BIT Mesra, Ranchi**. Built with HTML, CSS and vanilla JavaScript; no build step or package manager is required.

## Preview locally

Open `index.html` in a modern browser. For a local web server, from this folder run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

The folder can be deployed as a static site on GitHub Pages, Cloudflare Pages, Netlify, or any static web host. Upload the contents of this folder, keeping `index.html`, `styles.css`, `script.js`, and the `assets` directory together.

## Design direction

The design uses a formal institutional masthead, utility bar, sticky navigation, announcements, activity feed, training cards, image archive, contact/footer links, and a navy/white foundation with NCC flag-colour accents. This takes cues from common information architecture on official NCC websites, including:

- https://nccindia.gov.in/
- https://nccdtebj.in/
- https://ncc.delhi.gov.in/

It is a new layout, not a copy of another NCC site's source or branding. The shield-like initials element is a visual placeholder and is **not** the official NCC crest.

## Content and verification notes

- Historical dates and designations use the scanned “Brief History” document supplied by the user.
- Documented activity highlights are based on BIT Mesra's 2024–25 outreach report and NCC Directorate Bihar & Jharkhand public activity pages.
- Figures are explicitly marked as historical/report-period values, not current statistics.
- Current unit leadership, phone/email, enrolment schedules, eligibility and current training details have not been invented. Confirm them with BIT Mesra before launch.
- The main archival image is hotlinked from a BIT Mesra-hosted image URL. Confirm reuse permission and replace the image URL with an approved, locally hosted asset if needed.
- The non-photo gallery tiles are design placeholders and not depictions of real unit events.
- External font and archival image URLs need an internet connection; the layout remains styled with system fallbacks if fonts are unavailable.

## Before publishing as an official website

1. Get unit/institute approval for the content, name, identity and media.
2. Verify current leadership and approved contact information.
3. Confirm enrolment instructions and whether a current cadet application route is authorised.
4. Replace the placeholder mark and gallery graphics with approved branding and original unit photos.
5. Update the activities archive and achievements when official reports become available.
